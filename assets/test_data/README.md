# Synthetic test data

These files are **not real sequences**. They are randomly generated with a
conserved central region and divergent termini, sized so that the workflow can
be exercised in continuous integration in a few seconds.

They exist to verify that the pipeline wiring is intact. They cannot reproduce
any published result, and no biological conclusion should be drawn from a run
that uses them.

Real reference files are described in `assets/references/README.md`.
